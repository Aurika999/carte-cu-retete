# Rețete Tradiționale — Navigator React

Interfață React pentru PDF-ul „100 de Rețete Tradiționale”.

- Cuprinsul din PDF, paginile 21–23, este transformat într-un meniu navigabil.
- Click pe o rețetă → pagina rețetei se deschide în panoul din dreapta.
- Căutare în cele 99 de rețete listate în cuprins.
- Categorii expandabile.
- Layout responsive pentru mobil.
- PDF-ul original este inclus în `public/RETETE-TRADITIONALE-.pdf`.

## Pornire

Necesită Node.js 18+.

```bash
npm install
npm run dev
```

Pentru build de producție:

```bash
npm run build
```
